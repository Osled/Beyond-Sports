# Character art prompts

One image per form, saved as `src/art/<form id>.png` (transparent PNG, portrait 3:4). A file there
replaces the drawn placeholder automatically.

Evolved forms follow the game's design language: masks or visors over the eyes, armored
bodysuits, straps and belts, flowing ribbons, large wings and a spirit familiar behind the
strongest forms. Every humanoid form is written as an adult; charm and familiar stages are an
object and an animal. These are original characters; keep prompts free of existing franchise or
character names.

Shared style suffix, appended to every prompt:

> anime game character illustration, full body, single character, dynamic pose, clean cel shading, crisp line art, vibrant colors, plain white background, no text
